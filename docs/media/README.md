# Media

Published carousel slides, one folder per post date. Written by the `stage`
step of `recipe-social` and committed so the URLs stay live.

**This directory is the TikTok-verified URL prefix.** When TikTok's developer
portal gives you a verification file, drop it in `docs/` (for a prefix of
`https://<user>.github.io/<repo>/`) or here (for a prefix of
`https://<user>.github.io/<repo>/media/`), commit, and click Verify. The prefix
you verify must match `PAGES_BASE_URL` — TikTok refuses to fetch images from an
unverified prefix.

Do not rename or delete dated folders for posts that are already live; the
platforms fetch these URLs at publish time and some keep re-fetching afterwards.
